# deblasis/homebrew-tap

```sh
brew install deblasis/tap/incoda
brew install deblasis/tap/zioscp
```

Homebrew tap for:

- [incoda](https://github.com/deblasis/incoda): keyed, machine-local job lane for builds, tests and AI-agent fleets
- [zioscp](https://github.com/deblasis/zioscp): drop-in `scp` replacement in Zig (resumable, parallel, pipelined SFTP)

Each formula installs the prebuilt macOS binary from GitHub releases.
